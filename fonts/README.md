# Font

Copie dei font usati dal sito, servite da qui invece che da Google Fonts (così nessuna visita manda dati a Google).
Solo i sottoinsiemi `latin` e `latin-ext`, in woff2; le regole `@font-face` sono in cima a `styles.css`.

| File | Font | Licenza |
|---|---|---|
| `bricolage-grotesque-*` | Bricolage Grotesque (variabile, pesi 400–800) | SIL Open Font License 1.1 |
| `instrument-serif-*` | Instrument Serif (normale e corsivo) | SIL Open Font License 1.1 |
| `jetbrains-mono-*` | JetBrains Mono (variabile, pesi 500–600) | SIL Open Font License 1.1 |

Testo della licenza: https://openfontlicense.org/open-font-license-official-text/
I file sono quelli distribuiti da Google Fonts (fonts.google.com), scaricati l'8 novembre 2026 e non modificati.
